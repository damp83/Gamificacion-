# Tipografías

Las dos familias se sirven **desde este repositorio**, no desde un CDN. En un
centro educativo la red puede bloquear `fonts.googleapis.com` o caerse a mitad
de sesión, y una plataforma que se despinta a medio uso no es una plataforma
profesional. Además, así la versión de un solo archivo funciona igual desde un
USB, sin conexión.

Solo se incluye el subconjunto **latin** de cada una (lo que necesita el
castellano). Pesan 66 KB en total.

| Archivo | Familia | Uso |
|---|---|---|
| `bree-serif-latin.woff2` | Bree Serif | Titulares |
| `nunito-latin.woff2` | Nunito (variable, 400–800) | Texto |
| `nunito-italic-latin.woff2` | Nunito cursiva | Citas y matices |
